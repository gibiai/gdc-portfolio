# Gabriele De Carlo — Data Analyst Portfolio 📊

Cyberpunk-themed portfolio showcasing data analysis projects, technical skills, and visual storytelling. Built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no build step.

🔗 **[gdcportfolio.vercel.app](https://gdcportfolio.vercel.app)**

---

## Features

- **Animated canvas background** — data flow visualization and 3D wireframe globe, both reactive to mouse movement
- **Interactive Power BI dashboards** — embedded reports on a dedicated page
- **Glitch & neon UI** — custom text effects, tilt cards, and scroll-reveal animations
- **Fully responsive** — desktop, tablet, and mobile

## Tech Stack

| Layer | Tech |
|---|---|
| Structure | HTML5 |
| Styling | Vanilla CSS3 — Grid, Flexbox, CSS Variables, Keyframe Animations |
| Logic & Visuals | Vanilla JavaScript — HTML5 Canvas API |
| External | `vanilla-tilt.js` |
| Fonts | Orbitron, Share Tech Mono, Outfit, JetBrains Mono (Google Fonts) |
| Hosting | Vercel |

## Run Locally

Static files — no build step required.

```bash

cd gdc-portfolio
# Open index.html in any modern browser

```
