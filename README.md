# Gabriele De Carlo — Data Analyst Portfolio 📊

A premium, cyberpunk-themed portfolio built to showcase data analysis skills, projects, and visual storytelling capabilities. Features a fully custom animated 3D-feel data background, interactive data visualizations, and a sleek responsive layout.

## ✨ Key Features

- **Interactive Canvas Animations**: 
  - Dynamic "Data Flow" background with moving data packets that react to mouse speed.
  - Interactive 3D wireframe globe that rotates based on cursor position and explodes on click.
  - Simulated animated scatterplot (`CLUSTER_ANALYSIS`) with trendline and pulsating nodes.
- **Modern UI/UX**:
  - Glitch text effects and a carefully crafted neon color palette (`Teal`, `Violet`, `Yellow`).
  - 3D Tilt effects on project cards using `vanilla-tilt.js`.
  - Smooth scroll reveal animations using `IntersectionObserver`.
- **Performance & Lightweight**:
  - Zero heavy frontend frameworks.
  - Built purely with HTML5, CSS3, and Vanilla JavaScript.
  - Total code footprint is incredibly small and fast.
- **Fully Responsive**: Optimized seamlessly for Desktop, Tablet, and Mobile views.

## 🛠️ Tech Stack

- **Structure**: HTML5 (Semantic)
- **Styling**: Vanilla CSS3 (CSS Grid, Flexbox, CSS Variables, Keyframe Animations)
- **Logic & Visuals**: Vanilla JavaScript (HTML5 Canvas API, Math calculations)
- **External Libraries**: `vanilla-tilt.js` (for 3D card hover effects)
- **Typography**: *Orbitron*, *Outfit*, *Share Tech Mono*, and *JetBrains Mono* (via Google Fonts)

## 🚀 How to Run

Since the project is built with static files, no build step is required:

1. Clone or download the repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. *(Optional)* For the best development experience, use a local server like VS Code's "Live Server" extension.
